\# ORBITGUARD X — Mission Trust Console



A cybersecurity telemetry and command validation simulator built for SHOURYA '26: VYOM.



\## Features

\- Schema and policy validation

\- Timestamp and payload-range checks

\- Replay and out-of-order sequence detection

\- Audit logging with decision reasons

\- SHA-256 hash-linked, tamper-evident audit records

\- Synthetic threat scenario testing

\- Flask dashboard and automated tests
